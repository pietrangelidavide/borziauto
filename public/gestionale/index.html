              Come si aggiorna

              Il sito si aggiorna con un file che contiene le tue auto e le foto. Toccando il pulsante qui sotto il file parte direttamente: se non hai chi cura il sito, scaricalo e mandalo a chi lo gestisce.

              Il sito mostra le novità pochi minuti dopo che il file è stato caricato. Targa, costi, prezzi di vendita, note e contatti non sono nel file: restano solo qui.

              Per chi gestisce il sito (GitHub e Cloudflare)
              1. Decomprimi lo zip: contiene data/auto.json e le foto in img/auto/.
              2. Sul repository GitHub del sito apri la cartella public → Add file → Upload files e trascina dentro le cartelle data e img. Si uniscono a quelle esistenti e i file con lo stesso nome vengono sostituiti → Commit changes.
              3. Cloudflare ripubblica il sito da solo in un paio di minuti. Poi ricarica questa pagina: in alto comparirà «Il sito è aggiornato».

              Solo i dati, senza foto nuove: da caricare in public/data.

              Con l’archivio online attivo (Worker e database D1, vedi LEGGIMI) questo passaggio non serve più: ogni modifica va sul sito da sola.

              Controlli prima della vendita

              Per ogni voce scegli A posto, Da fare (con il costo del lavoro) o Non c’è. I costi dei lavori entrano nel calcolo del margine. Le voci «indispensabili» (documenti e sicurezza) vanno risolte prima di mettere l’auto in vendita. Resta tutto riservato: non va sul sito.
